    Outputs, figures and reports¶

    swingpy.report ¶

    Everything a simulation produces, written to one folder.

    from swingpy.report import report_run, report_breakthrough

report_run(model, run, "Results/Case one")             # a cycle run to steady state
report_breakthrough(model, result, "Results/Breakthrough")   # a single feed step

    Each writes the CSV files of swingpy.analysis, the figures of swingpy.plotting (when matplotlib is installed) and Summary.md, a readable summary with the performance, the tables and the list of files.

    Write the full report of a cycle run.

    		 None

    swingpy.analysis ¶

    Numbers of a simulation, without plotting: breakthrough metrics, the tables of a cycle, and export of profiles and histories to CSV files.

    from swingpy import analysis

metrics = analysis.breakthrough_metrics(model, result, "CO2")
rows = analysis.step_table(model, run.results)
analysis.export_run(model, run, "Output/Case one")   # CSV files

    Flows are molar flows in mol/s, positive out of the column; pressures in bar, temperatures in K, loadings in mol/kg, positions Z from 0 (feed end) to 1 (product end).

    GAS_CONSTANT = 8.314 module-attribute ¶

    Histories at the column ends.

    BreakthroughMetrics dataclass ¶

    Characteristic numbers of a breakthrough of one component.

    Attributes:

    Name Type Description
    component str

    The component.
    feed_mole_fraction float

    Its mole fraction in the feed.
    breakthrough_times dict

    {level: time, s} at which the outlet mole fraction first reaches level times the feed value (NaN if never).
    stoichiometric_time float

    Time at which the amount fed equals the amount retained by the column at the end of the step, s: the time a front without dispersion would break through.
    retained float

    Moles of the component retained by the column (adsorbed and in the gas) over the step, mol.
    dynamic_capacity float

    Change of the mean loading over the step, mol/kg.
    mass_transfer_zone float

    Length of the zone between the lowest and the highest of levels, estimated for a front of constant pattern as the front speed (column length over stoichiometric time) times the time between them, m; NaN if the outlet does not reach both. A value longer than the column means the front is not of constant pattern (for example two transitions in an adiabatic column).
    peak_outlet_temperature float

    Highest outlet temperature, K.
    peak_time float

    Time of that maximum, s.

    end_flows(model, result, end='product') ¶

    Molar flow (mol/s, positive out of the column), composition, temperature and pressure of the gas crossing one end during a step.

    Returns:

    Type Description

    dict with "time" (s), "flow" (total, mol/s), "component_flows"

    (components x times, mol/s), "mole_fractions", "temperature" (K),

    "pressure" (bar).

    column_profiles(model, state) ¶

    Profiles along the column of one state: position Z, pressure (bar), temperature (K), wall temperature (K), mole fractions and loadings (mol/kg, components x cells).

    compressibility_range(model, results, eos, tolerance=0.05) ¶

    How far the gas is from ideal over a set of step results, the check of Casas et al. (Adsorption 18 (2012) 143) for a column model that uses the ideal gas law: the compressibility factor Z of an equation of state (swingpy.eos) at every output time and cell.

    Parameters:

    Name Type Description Default
    model

    The ColumnModel.

    		 required
    results

    StepResults (a cycle, or one breakthrough step).

    		 required
    eos

    An equation of state with the components of the model, in order.

    		 required
    tolerance

    Largest |Z - 1| reported as acceptable.

    		 0.05

    Returns:

    Type Description

    Dict with the smallest and largest Z, where they occur (step, time

    in s, position Z, pressure in bar, temperature in K) and ideal:

    whether |Z - 1| stays within tolerance.

    Parameters:

    Name Type Description Default
    model

    The ColumnModel.

    		 required
    result

    The StepResult of a step fed at the feed end.

    		 required
    component

    Name of the component.

    		 required
    levels

    Outlet mole fractions, as fractions of the feed value.

    		 (0.05, 0.5, 0.95)

    step_table(model, results) ¶

    One row per step of a cycle: duration, pressures at both ends at the end of the step, moles of each component leaving through each end (negative when entering), the stream each end belongs to, machine work and heat through the wall.

    cycle_summary(model, run) ¶

    Performance of the last cycle of a run, the composition of each labelled stream and the convergence state.

    stream_table(model, run) ¶

    Net moles of each component in each labelled stream per cycle (out of the column positive).

    convergence_table(history) ¶

    KPIs of every cycle of a run.

    profile_table(model, results) ¶

    Profiles along the column at the end of every step (one row per step and cell).

    cycle_history_table(model, results, positions=(0.0, 0.25, 0.5, 0.75, 1.0)) ¶

    Time series of one cycle: pressures, temperatures and compositions at a few positions, and the flows through both ends (one row per output time).

    step_history_table(model, result, positions=(0.0, 0.25, 0.5, 0.75, 1.0)) ¶

    Time series of one step (for example a breakthrough), as cycle_history_table.

    write_csv(path, rows) ¶

    Write a list of dicts (same keys) as a CSV file; a dict is written as key,value rows.

    Write the numbers of a cycle run as CSV files in folder: summary, steps, streams, convergence, profiles at the end of every step and the time series of the last cycle.

    Returns:

    Type Description

    Returns:

    swingpy.plotting ¶

    Figures of SwingPy (they need matplotlib: pip install matplotlib).

    Every figure follows one engineering journal style. The axes are open (no top or right spine), the ticks point outwards, there is no grid, the type is an Arial-metric sans serif, legends have no frame, panel letters stand on the title line, and each figure is saved twice: as a 300 dpi PNG and, next to it, as a vector PDF.

    The figures carry no colour except in the position-time maps. Curves are told apart by their grey level and their line style. Results of the model are drawn as lines without markers; open markers (outline only, no fill) are kept for measured or published values, where there is no line to draw. Maps use the perceptually uniform viridis scale with labelled contours, as recommended by Crameri, Shephard and Heron, Nat. Commun. 11 (2020) 5444.

    Cycle steps are named by four-letter codes (see STEP_CODES): PRES for pressurization with feed, FEED for the feed (adsorption) step, BLOW for blowdown, EVAC for evacuation, and so on. A figure writes the name a step was given; when a long name does not fit, its code is written instead.

    INK = '#000000' module-attribute ¶

    Colour of single curves, reference lines, frames and text.

    GREYS = ['#000000', '#555555', '#8C8C8C', '#B8B8B8'] module-attribute ¶

    Grey levels of the curves of a line plot, darkest first.

    REFERENCE = '#6B6B6B' module-attribute ¶

    Colour of reference and tolerance lines.

    LINESTYLES = ['-', '--', '-.', ':', (0, (5, 1.5, 1, 1.5, 1, 1.5)), (0, (8, 2)), (0, (3, 1, 1, 1)), (0, (1, 1))] module-attribute ¶

    Line styles of the curves of a line plot, in order.

    MARKER_CYCLE = ['o', 's', '^', 'D', 'v', 'p', 'x', '+'] module-attribute ¶

    Open markers of measured or published values, in order.

    SEQUENTIAL = 'viridis' module-attribute ¶

    Colour scale of the position-time maps.

    STEP_CODES = {'PRES': 'pressurization', 'FEED': 'feed (adsorption)', 'BLOW': 'blowdown', 'EVAC': 'evacuation', 'PURG': 'purge', 'LPPR': 'light product pressurization', 'EQDN': 'pressure equalization, depressurization (donor)', 'EQUP': 'pressure equalization, pressurization (receiver)', 'LREF': 'light reflux', 'HREF': 'heavy reflux', 'HEAT': 'heating', 'COOL': 'cooling', 'HEVA': 'heating under evacuation', 'DESO': 'desorption', 'DEPR': 'co-current depressurization', 'RINS': 'rinse', 'RECY': 'recycle', 'SUPP': 'supply of purge to another column', 'IDLE': 'idle'} module-attribute ¶

    The four-letter codes of cycle steps and their meaning. Numbered steps of the same kind take the digit in the fourth place: EQD1 and EQD2 are the first and second equalization depressurizations, EQU1 and EQU2 the matching pressurizations, HEA1 and HEA2 two heating steps.

    STEP_LINE = dict(color='#7A7A7A', linewidth=0.7, linestyle=(0, (1.5, 2.0))) module-attribute ¶

    Style of the dotted lines that separate the steps of a time history.

    CYCLE_LINE = dict(color='#444444', linewidth=0.8, linestyle=(0, (5, 3))) module-attribute ¶

    Style of the dashed lines that separate the cycles of a time history.

    FIGURE_NAMES = {'profiles': 'Profiles', 'cycle_pressure': 'Cycle pressure', 'end_flows': 'End flows', 'end_compositions': 'End compositions', 'step_balance': 'Step balance', 'heatmaps': 'Maps', 'feed_step_profiles': 'Feed step profiles', 'last_cycle': 'Last cycle', 'last_3_cycles': 'Last three cycles', 'last_10_cycles': 'Last ten cycles', 'convergence': 'Convergence', 'energy': 'Energy'} module-attribute ¶

    File names of the figures written by plot_all, after the prefix.

    step_meaning(name) ¶

    The meaning of a step code ("EQD1" -> "pressure equalization, depressurization 1"), or None when the name is not a known code.

    step_code(name) ¶

    A short form of a step name for a narrow space: the name itself when it is already a code of four characters or fewer, the code of a known long name (pressurization -> PRES), and otherwise its first four letters in capitals.

    single_style(points=None, markers=False) ¶

    Style of a lone curve: black and solid. With markers it carries sparse open circles, for measured values drawn as a line.

    series_style(index, points=None, markers=False) ¶

    Style of the index-th curve of a line plot: a grey level and a line style. Results of the model carry no markers. With markers the curve carries sparse open markers (outline only), for measured values drawn as a line; points is the number of points of the curve and sets how sparse they are.

    open_marker_style(index) ¶

    Style of the index-th set of measured or published values drawn as points only: an open marker in the grey level of that index, no line.

    formula(name) ¶

    A component name with the digits of its chemical formula as subscripts: CO2 -> CO\(_2\).

    symbol(letter, name) ¶

    A quantity of one component in mathtext, for example symbol("y", "CO2") -> \(y_{\mathrm{CO_2}}\).

    units(text) ¶

    Powers inside the unit brackets of a label as superscripts: "Flow [m3/h]" -> "Flow [m\(^3\)/h]".

    apply_style() ¶

    Set the matplotlib defaults shared by every figure.

    label_panels(axes, letters='abcdefgh') ¶

    Put (a), (b), ... in front of the title of each panel, on the same line, or alone when a panel has no title. The letters are applied again when the figure is saved, so a title set later keeps its letter.

    save_figure(figure, output_path) ¶

    Save the figure as a PNG and, next to it, as a vector PDF, then close it.

    Name Type Description Default

    The ColumnModel.

    		 required

    		 required
    output_path

    Pressure, temperature, mole fraction and loading against time over several consecutive cycles, at a few positions along the column. Dotted lines separate the steps and dashed lines the cycles, and the steps are named above the top panel, so the approach to (or the repetition of) cyclic steady state can be seen at a glance.

    		 required

    PNG path; a PDF is saved next to it.

    		 required
    positions

    Dimensionless positions Z where the histories are taken (0 is the feed end, 1 the product end); the nearest cell is used.

    		 (0.0, 0.5, 1.0)
    component

    		 None

    plot_convergence(history, output_path, tolerance=None, profile_tolerance=None) ¶

    Purity and recovery, mass balance error, and profile change of every cycle (CycleRun.history). Optional tolerances are drawn as dashed lines.

    plot_cycle_pressure(model, results, output_path) ¶

    The pressure history of one cycle at the feed end and at the product end of the column, with the steps separated and named: the usual cycle diagram.

    plot_end_flows(model, results, output_path) ¶

    Molar flow of every component through the feed end and the product end over one cycle, positive out of the column, with the steps separated.

    plot_end_compositions(model, results, output_path) ¶

    Composition of the gas leaving each end of the column over one cycle, shown only while gas flows out, with the steps separated: the outlet analyser traces of an experiment.

    plot_step_balance(model, results, output_path) ¶

    Moles of each component leaving (positive) or entering (negative) the column through each end in every step of one cycle, as horizontal lollipops: one row per step, one marker per component.

    plot_energy_breakdown(results, output_path) ¶

    Work of the compressors and vacuum pumps in each step of one cycle, kJ, as horizontal lollipops.

    plot_heatmaps(model, results, output_path, component=None) ¶

    Mole fraction, temperature and loading over position and time in one cycle, as viridis maps with labelled contours at 10, 50 and 90 % of the range of each map (where the fronts are).

    plot_step_profiles(model, result, output_path, times=6, component=None) ¶

    How the column changes during one step: pressure, temperature, mole fraction and loading along the column at times moments, for example the front moving through the bed in a feed step.

    		 None
    profile_tolerance

    Profile change tolerance of the steady state, drawn on the convergence figure.

    Type Description

    swingpy.reporting ¶

    Plain text tables for console reports.

    Every script reports its results as small aligned tables with four columns: the quantity, the value computed here, the value given in the reference (a published or measured value, when there is one), and the relative difference between the two. Keeping the formatting in one place makes the output of all scripts look the same.

    print_heading(text) ¶

    Print a section heading followed by an empty line.

    format_value(value, digits=3) ¶

    Format a number compactly: fixed point for ordinary sizes, scientific otherwise.

    relative_difference(value, reference) ¶

    Relative difference to the reference, as text, or an empty string.

    print_table(rows, show_reference=True) ¶

    Print rows of (quantity, value, unit) or (quantity, value, unit, reference value) as an aligned table. Values may be numbers or ready made strings; a number may also be given as (number, digits) to control the precision.

    print_grid(row_header, row_labels, column_labels, values, number_format='{:.2e}') ¶

    Print a two dimensional table of numbers, for example one row per number of cells and one column per numerical scheme. values[i][j] belongs to row i and column j.
